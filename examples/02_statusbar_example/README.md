# 02_statusbar_example - wEui状态栏功能示例

## 概述
这个示例专门展示wEui库的状态栏功能，包括动态状态显示和系统监控。

## 展示功能
- 状态栏的启用/禁用
- 动态状态信息更新
- 系统状态监控
- 多种状态显示模式
- 状态栏边框控制

## 功能演示
### 菜单选项
- **切换状态栏**: 启用或禁用状态栏显示
- **切换边框**: 控制状态栏边框的显示
- **模拟状态**: 循环演示不同的系统状态
- **系统信息**: 显示当前内存使用情况
- **连接状态**: 模拟WiFi连接状态切换

### 动态更新
- 自动循环显示运行时间、加载状态、电量等信息
- 模拟电池充放电过程
- 系统监控和警告提示

## 状态类型演示
1. **空闲状态**: 显示系统运行时间
2. **加载状态**: 动画效果的加载指示
3. **连接状态**: 在线状态和电量显示
4. **错误状态**: 错误编号显示
5. **低电量状态**: 电量警告提示

## 适用场景
- 需要系统状态显示的项目
- 实时监控应用
- 状态栏功能学习和测试

## 学习重点
- 状态栏API的使用方法
- 动态内容更新技巧
- 多任务协调的状态显示
- 系统状态监控的实现

## 技术特点
- 多任务协同更新状态栏
- 智能的状态切换逻辑
- 电池电量模拟算法
