# 03_page_management - wEui页面管理系统示例

## 概述
这个示例展示wEui库的高级页面管理功能，演示如何创建复杂的多级菜单系统。

## 展示功能
- 多级页面堆栈管理
- 列表页面和自定义页面
- 页面间的导航和数据传递
- 自动返回处理
- 多页面列表上下文切换

## 页面结构
```
主菜单
├── 设置
│   ├── WiFi设置
│   │   ├── WiFi开关
│   │   ├── 网络扫描
│   │   └── 连接状态
│   ├── 显示设置
│   │   ├── 亮度调节
│   │   ├── 声音开关
│   │   └── 重置设置
│   └── 系统信息 (自定义页面)
└── 关于 (自定义页面)
```

## 核心特性
### 页面类型
1. **列表页面**: 使用内置列表系统的标准菜单页面
2. **自定义页面**: 使用自定义渲染函数的特殊页面

### 导航特性
- 最多10层页面堆栈深度
- 自动返回键处理
- 页面状态保持
- 智能菜单恢复

### 数据管理
- 全局设置状态管理
- 页面间数据同步
- 动态菜单项更新

## 自定义页面
### 系统信息页面
- 设备名称显示
- 内存使用情况
- 页面堆栈深度
- WiFi状态显示

### 关于页面
- 版本信息
- 功能特性介绍
- 操作说明

## 设置功能演示
- **WiFi设置**: 开关WiFi、扫描网络、查看状态
- **显示设置**: 亮度调节(20%-100%)、声音开关、设置重置
- **系统信息**: 实时显示系统状态信息

## 适用场景
- 复杂的嵌入式设备设置界面
- 多级菜单系统
- 需要页面导航的应用

## 学习重点
- 页面管理API的使用
- 自定义页面渲染技巧
- 多页面数据管理
- 自动导航逻辑实现

## 技术亮点
- 智能的页面堆栈管理
- 自动化的返回处理
- 灵活的页面类型系统
- 状态栏与页面的联动
