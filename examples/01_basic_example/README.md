# 01_basic_example - wEui基础使用示例

## 概述
这个示例展示了wEui库的基础功能，是学习wEui的起点。

## 展示功能
- wEui系统初始化
- 基本菜单列表创建
- 按钮事件处理
- FreeRTOS任务管理
- 基本的UI渲染循环

## 代码结构
- **硬件配置**: 引脚定义和硬件初始化
- **菜单回调**: 简单的菜单项回调函数
- **任务管理**: UI、按钮、GUI服务任务
- **初始化流程**: 完整的系统初始化过程

## 适用场景
- 初次学习wEui库
- 理解基本的嵌入式UI架构
- 作为新项目的起始模板

## 使用说明
1. 根据您的硬件调整引脚配置
2. 编译并上传到ESP32设备
3. 使用按钮进行菜单导航
4. 观察串口输出了解系统行为

## 学习重点
- wEui的基本配置方法
- FreeRTOS任务的创建和管理
- 菜单系统的基本使用
- 按钮事件的处理流程
